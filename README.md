# YDCC2025---GreenWarriors

## Shrimp AI Guard

This repository contains the Shrimp AI Guard Flutter application - an AI-powered shrimp monitoring system.

### Project Structure

```
shrimp_ai_guard/    - Flutter mobile application
```

### Flutter Application

The `shrimp_ai_guard` directory contains a Flutter application with the following packages:

- **camera** (^0.10.5+5) - Camera access for capturing shrimp images
- **tflite_flutter** (^0.10.4) - TensorFlow Lite for on-device AI inference
- **image** (^4.1.3) - Image processing (resize, crop) before AI analysis
- **sqflite** (^2.3.0) - Local SQLite database for offline data storage
- **path_provider** (^2.1.1) - File system path utilities
- **connectivity_plus** (^5.0.2) - Network connectivity status monitoring
- **dio** (^5.4.0) - HTTP client for server communication
